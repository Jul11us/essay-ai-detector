# 样本评测面板与 Word 标注报告

在本机网站顶部选择「样本评测」。所有模型推理仍通过本机检测服务，报告统计不需要模型已加载；新样本评测须等清单中所需语言的模型就绪。

## 查看已有评测

点「导入评测报告」，选择 `backend/benchmark.py` 生成的 `report.json`，或面板导出的 `evaluation-report.json`。需要逐样本 `records`；面板忽略传入的汇总值和阈值配置，根据记录重新汇总及拟合，避免显示无法核对的百分比。

此前的本机 HC3 试评保存在项目的 `experiments/benchmark-private/public-hc3/report.json`。这是 Git 忽略的本机文件，仓库不会分发原稿或私人评测记录。导入后默认展示独立测试集，可按语言、来源、非空白字符长度、作者组别和集合组合筛选。分页展示全部匹配样本，每页 25 份；导出包含整轮记录，不受筛选影响。

误报定义为 human 样本判成较高，漏报定义为 ai 样本判成较低。两类不确定单列，不能计作正确识别。混合稿仅报告档位分布，不计算二元准确率或 AI 字数比例。Wilson 95% 区间描述这些样本的比例，同问题组的重复版本可能相关，不能把它解读为总体作文性能保证。

## 运行带标签的本机样本

1. 点「下载清单模板」，替换示例编号、文件名、语言、来源、许可和标签；模板不提供已知真值的正文。
2. 导入 JSONL 清单（每行一份样本），或同格式的 JSON 数组。
3. 多选对应 `.txt`、`.docx` 或文字版 PDF 正文文件，点「开始样本评测」。最多 1000 份，每份最多 20 MB；扫描 PDF 仍需先转为文字版。
4. 查看完成／失败进度，必要时停止本轮。失败与取消不计入指标，面板显著标明完成数与计划数，任何不完整运行均不能产生可启用状态。
5. 下载评测报告或候选阈值配置。文件由浏览器保存，不写入服务器样本库。任务中心会在浏览器本机保存原文件和完成记录；刷新或关闭页面后，打开任务并手动继续未完成样本。已完成样本不会重复计入。

```json
{"id":"human-001","file":"human-001.txt","lang":"en","label":"human","source":"本人原稿，有写作过程记录","license":"本人授权本机评测","split":"descriptive","group_id":"essay-001","writer_group":"未核验","training_overlap":"unknown"}
```

`lang` 为 `en` 或 `zh`；混合写作标签用 `label: "mixed"`，仍须指定本次评分语言。`file` 是相对文件名，可含清单目录下的子目录；普通多选上传按唯一文件名匹配，重名时会拒绝，须分开评测。可提供 `text_sha256` 核对原始文件，评测时也会生成实际文件指纹。

标签为 `human`、`ai`、`mixed`，须有来源依据，不得把检测器输出当作真值。公开材料建议填写 HTTP(S) `source_url`、`license`、`dataset_revision`、`domain` 和生成模型版本；自写或授权材料不要求公开私人正文。`writer_group` 记录已知作者条件，未知时明确标为未知。

若拟合阈值，所有样本须分到 `calibration` 或 `test`。同一原稿、题目的人写／AI／改写／混合版本使用同一 `group_id`，整组不得跨集合；完全重复的文件不得跨集合或虚增独立组别。同一语言不得混入不同模型或权重版本。只做描述性评测时，所有样本使用 `descriptive`。

来源和标签均由使用者提供。导入记录的真值、检测来源及排除训练重叠的证据仍需人工核验；面板不是认证工具。下载的评测报告采用字段白名单，输出不含作文正文、摘录或本机输入路径。本机任务记录则包含原文件，以供恢复；可在任务中心删除。

## 校准状态

只用 calibration 的人写／AI 样本拟合阈值；test 与 mixed 不参与选择。筛选只改变图表，不重新拟合。面板显示整轮的校准与测试样本数、候选阈值、独立测试指标、适用长度／题材、实际模型版本及拒绝原因。

默认约束与命令行一致：每类、每集合至少 30 个独立样本／问题组，误报与漏报的 Wilson 95% 上界各不超过 20%；来源、完整 API 流程、输入指纹、确切权重版本和排除训练重叠证据须可核验。未满足者为 candidate 或 unvalidated。通过也仅说明提供的记录满足策略，不能外推至未覆盖作文或作者条件。

查看、拟合和下载均不会写入运行中的阈值配置。确有可核验证据后，才可按 [评测说明](benchmark.md) 人工配置 `DETECTOR_CALIBRATION_PATH`；运行时还会验证配置及模型匹配。

## Word 标注报告

在单语言结果中点「导出 Word 标注报告」，中英结果中也可点「导出中英 Word 报告」。生成 `.docx`，浏览器负责选择下载位置。

报告使用按钮点击时的当前结果，包括已经修改、重测过的段落。已评分句子按默认 40%／75% 门槛着色；未评分句子无色。尚未完成逐句评分、或旧句子无法对应当前正文时，保留完整段落并显示说明，不用旧句子替换新稿。全文门槛与句子着色的校准范围分开说明。

报告包含段落分数表、当前正文、未参与评分的内容、语言部分失败信息、模型／权重版本、校准状态与局限。它是模型结果快照，不是学校或第三方机构报告，不还原原上传文件的版式、图片、脚注或批注。
