# 可复现公开语料：HC3 问答试评

这套语料用于检查当前 `/api/detect` 的真实结果和阈值选择，不代表学生作文或最新大模型的检测效果。

使用作者发布的 [HC3 英文数据](https://huggingface.co/datasets/Hello-SimpleAI/HC3)、[HC3 中文数据](https://huggingface.co/datasets/Hello-SimpleAI/HC3-Chinese)。[原论文](https://arxiv.org/abs/2301.07597)于 2023 年发布，比较人类和 ChatGPT 对相同问题的回答；具体 ChatGPT 模型版本未在所用记录中注明。

## 生成命令

在项目根目录运行；只需要 Python 3.10+ 标准库，无需 Hugging Face 令牌、模型权重或私人文章。

```powershell
py -3.12 scripts/prepare_benchmark.py
```

默认输出 `experiments/benchmark-private/public-hc3/`，该目录已被 Git 忽略。脚本限制输出位于 `experiments/benchmark-private/` 内；样本文本、下载缓存和本机报告都留在本机。不要强制添加这些文件到 Git。

| 文件 | 用途 |
| --- | --- |
| `manifest.jsonl` | 交给 `backend/benchmark.py` 的样本清单 |
| `preparation.json` | 固定版本、原始文件校验和、选样规则、计数和局限 |
| `samples/*.txt` | 完整答案；构造混合稿的组合方式在清单中明示 |
| `raw/*.jsonl` | 官方固定版本的原始来源缓存 |

首次运行下载官方文件；再次运行会验证缓存的 SHA256。校验和不匹配时中止，不自动接受不同版本。删除对应损坏缓存文件后可重新下载。

## 固定来源与许可

| 语言 | 官方数据集版本 | 使用的领域 |
| --- | --- | --- |
| en | `4d0ff18143b5a7e1b1e79beb540c04549d1e59d3` | `reddit_eli5`、`wiki_csai` |
| zh | `09a687b8dc164b89e7df95abf15df3b216bc31c2` | `open_qa`、`finance`、`psychology` |

每个源文件的 SHA256 固定在脚本中，并写入清单和 `preparation.json`。清单记录数据集 URL、原来源 URL、源文件行号、答案序号和正文 SHA256，可追溯到官方固定版本的原记录。

HC3 数据卡声明 CC-BY-SA-4.0，并要求继续遵守更严格的原数据集条款。[维护者的许可表](https://github.com/Hello-SimpleAI/chatgpt-comparison-detection#dataset-copyright)把本次使用的英文来源列为 BSD / CC-BY-SA，中文来源列为 MIT / CC-BY-4.0 / CC0。清单分别保存语料条款和原来源声明；未明确许可的领域与非商业医疗领域不在本次试评中。此脚本不授予额外使用权；需要再分发时应按相应许可处理署名和衍生作品条款。

## 选样与隔离

- 默认每种语言 60 个问题，每题一条真实人类答案、一条真实 ChatGPT 答案；总计 240 条原稿。
- 每语言 30 个问题用于 `calibration`，另外 30 个用于 `test`。同一个问题的所有文本共享 `group_id`，只出现在一个拆分中；相同正文的空白变体也被排重。
- 选样种子为 `20261002`。在各领域轮流取样，排序采用种子、来源和行号的 SHA256；多个人类/AI 答案时选择首条满足规则的完整答案。脚本不读取模型分数，不按模型输出挑样本。
- 英文完整答案限制为 400–2500 个非空白字符，并至少含 200 个英文字母；中文为 200–2500 个非空白字符，至少含 150 个汉字。语言比例规则只排除明显的语言不匹配。超长答案跳过，不裁剪或改写。
- 每语言追加 10 条 `mixed`，仅来自 `test` 内已有的成对答案：完整人类答案 + 两个换行 + 完整 AI 答案。英文混合稿最多 3500 个非空白字符，中文最多 2500 个。清单保存两个组成样本 ID、校验和与实际字符比例。
- 混合稿是公开原稿的人工组合，不是真实共同创作过程；不能将其字符比例当作模型目标概率。它们只用于描述性检查，排除在二分类指标和阈值拟合之外。

默认清单共 **260 条**。后端会按实际产品流程提取、排除标题/参考文献、分段和打分；原始答案的保存内容保持不变。

## 结果能够说明什么

这是一套小规模、按领域和长度限制选择的问答试评。人类作者身份、母语、年龄和写作背景未知；`writer_group` 只记录“公开问答作者未注明”“HC3 ChatGPT”“构造混合稿”，不推断母语或学生身份。

不能排除检测模型曾用 HC3 或相关来源训练，所以该试评不能作为独立的分布外验证。这里的 `test` 只表示与本次阈值拟合的问题组隔离，不能证明与模型训练语料隔离。HC3 的训练重叠状态应保持 `unknown`；在未验证模型训练隔离前，候选阈值不能升级为可启用的校准结果。

阈值只在 `calibration` 上选择，`test` 用于之后报告；重看测试结果再调参就不再是独立测试。学生作文、非母语作者、不同体裁和现代模型需要另建有授权、来源明确且独立的数据集。这里只提供阈值试验依据，不能把原始分数解释成 AI 写作字数比例、作者身份或通用准确率。
