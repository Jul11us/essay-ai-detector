# 中文论文校准：暂不启用

[C-ReD 论文节选试验](https://github.com/Jul11us/essay-ai-detector/pull/4)只用校准组拟合门槛，再用未参与拟合的同语料测试组比较判定。候选保留较低门槛 0.40，将较高门槛提高到约 0.7872，并在实际评分内容达到 400 字时允许单段进入较高档。

| C-ReD 测试指标 | 默认 | 候选 |
| --- | ---: | ---: |
| 人写节选判较高（误报） | 0/120 | 3/120 |
| 人写节选判不确定 | 23/120 | 20/120 |
| AI 节选判较高 | 6/120 | 81/120 |
| AI 节选判不确定 | 114/120 | 39/120 |
| AI 节选判较低（漏判） | 0/120 | 0/120 |

候选的测试集误报、漏判 95% Wilson 上界分别为 7.1% 和 3.1%，低于各自的 10% 上限。但测试组独立于校准组，并不等于原文独立于模型训练集。[中文模型固定权重](https://huggingface.co/yuchuantian/AIGC_detector_zhv3/commit/47695ff451b32c225dd938f4f478f7fdc6aa6bb0)于 2025-06-24 发布；[C-ReD 固定版本](https://github.com/HeraldofLight/C-ReD/tree/b90072cd218b6ebdbd1d1478ce6e439677f18192)虽于 2026 年公开，论文 CSV 的 1,000 条人写记录的 `year` 都是 2017–2019 年，也没有逐篇许可及上游版本。候选因此不符合启用条件；节选结果也不能外推到完整论文。

## 样本来源核查

| 来源 | 当前结论 |
| --- | --- |
| [C-ReD](https://aclanthology.org/2026.findings-acl.2119/) | 可作试验参考；不能核实原文授权或排除训练重叠。 |
| [MGRD](https://doi.org/10.57760/sciencedb.33718) | 人写摘要来自 2011–2022 年；不能根据数据集发布时间排除训练重叠。 |
| [DetectRL-X](https://aclanthology.org/2026.acl-long.1773/) | 论文限定非商业学术研究用途，未给出可逐篇核查的人写原文首发时间和授权。 |
| [热带海洋学报](https://www.jto.ac.cn/CN/column/column284.shtml)、[海南大学学报（自然科学版中英文）](https://journal.hainanu.edu.cn/info/1002/2082.htm) | 期刊政策允许 CC BY 4.0 再利用；仍须逐篇核对最早版本、适用许可和人写证明。不能用仅有署名或缺少 AI 披露来确认人写标签。 |

## 下次验证

1. 收集新的校准组和独立测试组。人写稿保留原稿许可、最早版本时间和作者未使用生成式 AI 撰写的确认；AI 稿在固定权重发布之后独立生成，记录生成时间、模型版本、提示方式和使用许可。训练重叠证据不足时保持 `training_overlap=unknown`。保留署名和改动说明，不提交原文。
2. 在看分数前冻结入组标准、论文分组和两项 10% 误差上限。同论文版本、原稿及对应生成稿不得跨 split；排除跨 split 的近重复原文。预先区分摘要、引言节选和完整论文，不能只测节选就开启全文配置。
3. 用[现有评测命令](benchmark.md#中文作文与论文分别拟合)走实际 `/api/detect` 上传流程。在校准组拟合，在测试组核对 95% Wilson 上界，并按文档类型和 400 字门槛前后报告较低、较高与不确定。只有来源核查和两项误差上限都通过、且 AI 不确定数在独立测试中下降，才考虑使用该配置。
