# 功能说明

这里是各项功能的完整说明。项目总览、分数的读法和安装步骤见 [README](../README.md)；英文版见 [features.en.md](features.en.md)。

## 输入

粘贴文本，或上传 `.txt`、`.docx`（读正文和表格，不读页眉页脚、脚注、文本框）、文字版 PDF；上传后先预览提取到的内容

## 批量检测

每批最多 20 个文件，逐篇识别中英或混合语言，未完成文件可手动指定语言；失败单独重试、取消后续文件后继续；完成结果与局部复检保留；支持筛选、排序和分语言 CSV 汇总，超限会明确提示

## 语言

英文 Vanguard、中文 zhv3；中英混合文档可以分开评分

## 阅读结果

总分、段落与句子着色、全文构成、连续高分区段，以及常见套话和句长波动提示

## 复核与导出

固定侧栏阅读前后文，标记「已复核／待确认／需修改」，批注自动保存并支持撤销；手机使用底部抽屉；导出含原生评论和复核记录的 Word 报告（支持中英合并）、HTML、JSON、CSV，或打印

## 版本对比

段落重测自动留档，也可命名保存；逐段查看文字增删与分数变化，中英文分别比较；恢复旧版本时保留当前记录；每份结果保留初始版本及最近 19 次记录

## 写作过程时间线

按实际操作时间记录检测起点、修改重测、批注、版本保存与恢复；筛选节点并查看历史批注或打开对应稿件对比；最多 200 个节点，随任务保存在本机

## 检测范围

单文件预览中按提取段落选择，支持正文／正文与摘要快捷选择；后端核对原文件指纹，结果和报告记录所选范围及排除内容

## 任务中心

本机保存原文件、进度、结果、批注与版本；按名称或原文件名搜索，按类型和状态筛选，排序及重命名；刷新后手动恢复；最多 50 个任务，可逐项删除

## 可视化评测

在「样本评测」导入已有报告，或选择带标签和来源的样本清单及正文，用本机模型运行；按语言、来源、长度、作者组别和集合筛选，查看误报、漏报、不确定比例及候选阈值的独立验证

## 本地使用

Windows 双击启动和停止脚本；前端由 React/Vite 构建，后端由 FastAPI 提供接口

## 评测与校准

固定版本公开语料准备、实际 API 评分与预测重放、分组统计及置信区间；按原稿组隔离校准/测试，仅用校准集拟合全文阈值；未通过验证的候选不会启用

## 补充说明

### Word 标注报告

检测完成后点「导出 Word 标注报告」即可下载可编辑 `.docx`，保存到浏览器设置的下载位置。报告使用当前结果快照，保留分段正文、已评分句子的着色、段落分数、未评分内容和模型／校准说明；未完成逐句评分的段落会明确注明。它不保留上传原文件的版式、图片或脚注。

### 样本评测

「样本评测」的清单格式、已有本机试评报告位置和操作步骤见 [评测面板使用说明](evaluation-panel.md)。查看、拟合或导出候选阈值不会自动更改检测门槛。

### 本机任务数据与隐私

人工复核、范围选择和刷新恢复的步骤见 [使用说明](review-tasks-scope.md)。任务数据保存在当前浏览器、当前网站地址的 IndexedDB 中；关闭页面会中断前端队列，恢复后需手动继续。清除网站数据会删除记录。下载的评测报告不含原文，但本机任务记录包含原文和原文件。

### 写作过程时间线

结果上方的「写作过程与版本对比」记录本站的检测、重测、批注与版本操作。最多保留 200 个时间线节点和 20 份稿件快照；清除当前批注后历史仍保留，删除任务会一并移除。JSON 包含历史，Word、HTML 和 CSV 导出当前结果。不追踪外部编辑或键盘输入，不估算写作时长。
